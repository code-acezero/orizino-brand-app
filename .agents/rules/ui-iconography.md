# UI Iconography Rule

- **Rule**: Don't use sparkle (`Sparkles`) icons everywhere.
- **Guideline**: Always use semantic, contextual, and purposeful domain icons that accurately represent the action, object, or concept (e.g., `Boxes`/`Package` for inventory/stock, `QrCode`/`ScanLine` for barcodes/scanning, `CheckSquare` for bulk selections, `Truck` for shipping/logistics, `FileText` for documents, `Newspaper` for news/press). Reserve AI/sparkle icons solely for actual generative AI/LLM features.
